# Market Analysis

This project focuses on analyzing customer purchase behavior and product trends using data analytics tools such as SQL, Python, Excel, and Power BI. The goal is to extract meaningful insights from an e-commerce dataset and present them in a clear, business-friendly format.

## Overview

The repository contains SQL-based exploratory analysis on a retail order dataset, including product categories, order patterns, customer ordering behavior, and reorder trends. The analysis helps answer questions such as:

- Which departments and aisles have the highest product diversity?
- Which products are purchased most frequently?
- What is the reorder rate for products?
- When do customers place the most orders?
- How does order size vary across customers and products?

## Project Objective

The main objective of this project is to perform market analysis using real-world transactional data and derive insights that can support business decision-making, inventory planning, and customer behavior understanding.

## Key Analysis Areas

### 1. Product and Department Analysis
Explores which departments and aisles contain the largest number of products and the most active areas in the dataset.

### 2. Reorder Rate Analysis
Examines how often products are reordered and identifies products with high repeat purchase behavior.

### 3. Customer Behavior Analysis
Looks at customer activity, ordering patterns, and frequency of repeat purchases.

### 4. Order Timing Analysis
Analyzes order distribution by hour of the day and day of the week to identify peak shopping periods.

### 5. Order Size Analysis
Studies how many products are typically included in a single order and how order size varies.

## SQL Workflow
